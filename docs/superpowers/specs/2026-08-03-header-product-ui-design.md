# 页头与产品页 UI 调整设计

## 目标

根据确认的视觉需求，调整站点页头导航、产品详情 CTA 与品牌标语排版，不改变产品数据结构和页面交互框架。

## 方案

1. 页头桌面端和移动端“加入我们”统一链接到 `https://www.genuineknowledge.cn/joinus/`。
2. 产品模板仅对 HaiBao Data（第二个产品）隐藏“了解更多”按钮；HaiTun Agent 保持现有按钮和链接。
3. 页头左侧继续复用现有 logo 图片，在 logo 右侧将两行标语调整为紧凑的品牌锁定单元：引入适合中文品牌标题的外部字体，并配置可靠的系统字体回退；两行文字通过字重、字距、间距、行高和对齐方式与 logo 形成整体。
4. 仅修改 Hugo 模板、产品数据和现有 CSS；除字体样式资源外，不新增图片或 JavaScript 依赖。

## 验证

- 搜索模板确认两个“加入我们”链接均为目标地址。
- 构建 Hugo 站点，确认模板语法和页面生成成功。
- 检查生成的产品页中 HaiBao Data 不再包含详情按钮，HaiTun Agent 仍保留。
- 检查响应式 CSS，确保移动端标语和导航不溢出。
- 确认外部字体不可用时会回退到本地中文无衬线字体，文字仍清晰且布局稳定。
